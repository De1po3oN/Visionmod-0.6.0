VISION MOD 0.7.0 — КАК УСТАНОВИТЬ И ТЕСТИРОВАТЬ

1. Это полные исходники, НЕ готовый JAR.
2. Содержимое ZIP нужно положить в корень репозитория GitHub
   (папки src, .github, cloudflare и файлы build.gradle, settings.gradle).
3. На GitHub открой Actions -> Build Vision Mod 0.7.0 -> Artifacts.
   Сначала добейся успешной сборки; без неё не ставь JAR в игру.
4. Minecraft 1.21.11, Fabric Loader 0.19.3+, совместимый Fabric API, Java 21.
5. Клавиша меню — правый Shift, свободный обзор — удерживать левый Alt.
6. Нажми PERFORMANCE / FPS. При первом запуске стоит MAX FPS:
   - подсветка руд, косметика и сердечки отключены;
   - подавление частиц включено;
   - остальные основные функции не удалены.
7. Чтобы вернуть подсветку, нажми ORE OUTLINES: ON, затем вручную
   изменяй радиус / лимит проверок / предел контуров.
8. В любой момент можно выбрать BALANCED или VISUAL.
9. Для обмена профилями: CONFIGS -> SAVE; чужой JSON положить в
   config/visionmod/profiles/, затем REFRESH LIST -> LOAD.
10. Настройки Performance находятся в config/visionmod/performance.properties.

ВНИМАНИЕ: реальный выигрыш FPS не измерялся. Код оптимизирует только
собственные вычисления Vision Mod, не исправляет лаги сервера (TPS),
чужих модов, видеодрайвера и тяжёлых шейдеров.

Если что-то сломалось, пришли целиком лог GitHub Actions или latest.log.
