VISION MOD 0.2.0-compat — исходный проект клиентского Fabric-мода для Minecraft 1.21.11.

Это ИСХОДНЫЙ КОД (.zip), НЕ готовый мод (.jar). Для игры нужен JAR из GitHub Actions.
Версия Minecraft: 1.21.11. Java: 21. Fabric Loader >= 0.19.3. Fabric API 0.141.6+1.21.11.
Emotecraft, Sodium, Iris и Player Animation Library НЕ являются обязательными зависимостями.

Исправления по сравнению с присланным ZIP:
* Fabric Loader и Fabric API при компиляции согласованы с требованиями fabric.mod.json.
* PlayerHeartsMixin пропускается при наличии известных модов анимации игроков.
  В таком случае кнопка Hearts есть, но сердечки не рисуются.
* Необязательные точки перехвата частиц могут отсутствовать без фатального сбоя внедрения.
* Удалён случайный пустой файл ParticleSettingsScreen.jav.

Сохранены: Right Shift меню, End общий переключатель, FullBright, подсветка руд,
настраиваемые цвета через круг/квадрат/HEX, управление туманом и частицами.

ВАЖНО: это не гарантия полной совместимости. Другие моды могут изменять те же методы.
Нужна сборка в GitHub Actions и проверка запуска в игре. В этом окружении Gradle отсутствует,
поэтому компиляция и запуск Minecraft не проверены.

Как поставить:
1. Распакуйте ZIP. Загрузите СОДЕРЖИМОЕ папки VisionMod-main в корень GitHub-репозитория.
2. Дождитесь Actions -> Build Vision Mod -> успешный Build.
3. Скачайте артефакт VisionMod-1.21.11 и возьмите visionmod-0.2.0-compat.jar,
   а не sources/dev jar (если есть).
4. Удалите предыдущую версию Vision Mod из папки mods, затем установите новый JAR.
5. Держите Fabric API установленным в игре.

Если Minecraft вылетает, пришлите crash-reports/*.txt или logs/latest.log.
