VISION MOD 0.3.0 - COSMETICS PREVIEW
Minecraft 1.21.11 Fabric, Java 21

СДЕЛАНО:
- В главном меню появилась строка Cosmetics. ЛКМ включает/выключает, ПКМ открывает настройки.
- Выбор встроенных прототипов: голова none / ears / crown, спина none / wings / pack.
- Вывод простых цветных КОНТУРОВ аксессуаров в мире для первого теста (не текстурированные 3D-модели).
- Фоновое чтение косметики других игроков из Cloudflare Worker по UUID раз в ~30 секунд.
- Если Worker недоступен, Minecraft не должен падать из-за сетевого запроса.
- Клиент НЕ содержит административных ключей, не может менять чужие записи.

ПОКА НЕ СДЕЛАНО:
- Синхронизация ВАШЕГО локального выбора с Worker (нужна безопасная проверка владения аккаунтом).
- Загрузка/передача PNG и пользовательских 3D-моделей (потребуется R2 и валидация).
- Привязка моделей к наклону/повороту/анимации тела (контуры пока в мировых координатах).
- Не проверено компиляцией Gradle и запуском игры.

ВАЖНО: загрузи содержимое папки VisionMod-main в репозиторий, а не сам ZIP.
Запуск сборки: GitHub Actions, после успешной сборки взять build/libs/*.jar из Artifacts.

Тест API: https://rough-truth-7b7dvision-cosmetics.vision-mod.workers.dev/health
API для чтения: GET /cosmetics/<UUID>
Нужен Worker с публичным GET /cosmetics/<UUID>, который мы готовили ранее.
Если в KV ещё нет записей игроков, чужие аксессуары не появятся — это ожидаемо.

НОВОЕ (папка косметики):
- Кнопка DIR рядом с Cosmetics в меню.
- Кнопка OPEN COSMETICS FOLDER внутри настроек.
- Папки config/visionmod/cosmetics/head и back создаются автоматически.
- Пока пользовательские файлы не читаются: кнопка только открывает папку.
