VISION MOD 0.4.1 - СИНХРОНИЗАЦИЯ КОСМЕТИКИ

Исправлены:
- Выбор головного/спинного аксессуара отправляется по HTTPS в Cloudflare Worker.
- Получение выбранной косметики других игроков по UUID.
- JSON-модели из config/visionmod/cosmetics/head и back передаются вместе с выбранной косметикой.
- Для встроенных аксессуаров используются встроенные одинаковые модели.
- Режим ручного обновления не нужен, но KV может распространять изменения 60 секунд и дольше.
- Текущий статус UPLOADING / SYNCED / HTTP 404 / UUID CLAIMED отображается в Cosmetics.

ВАЖНО: Сначала вставить ПОЛНЫЙ код cloudflare/worker.js в Cloudflare Workers - Edit code - Deploy.
Проверить https://<ВАШ WORKER>/health: version 0.4.1.
KV binding по имени COSMETICS_KV уже должен быть подключен.

Затем в существующем GitHub заменить целиком только:
src/main/java/com/visionmod/VisionCosmetics.java
src/main/java/com/visionmod/CosmeticsScreen.java

Версия остается 0.4.1. Другие файлы НЕ заменяйте, чтобы не потерять новые исправления подсветки руд.
После коммита собрать GitHub Actions и установить новый JAR двум игрокам.

ОГРАНИЧЕНИЯ:
- Никаких новых PNG или .bbmodel: автоматически передаются только ограниченные цветные JSON-кубоиды.
- Оба игрока должны установить Vision Mod с этими изменениями и иметь доступ к Cloudflare.
- Без официальной проверки Microsoft/Mojang нет полноценного доказательства владения UUID.
  Реализована защита последующих записей ключом установки (first claim):
  кто первым зарегистрировал UUID, тот получает ключ редактирования.
  Злоумышленник может заявить неиспользованный UUID раньше владельца.
  Не использовать это как защищенный публичный сервис без дополнительной авторизации.
- Секретный файл config/visionmod/cosmetics-sync.properties не публикуйте и не удаляйте,
  иначе можно потерять право обновлять свою косметику (403 UUID CLAIMED).
- Cloudflare KV eventual consistency: чужая косметика может появиться через 1-2 минуты.
- Если Minecraft-сервер подменяет UUID, сопоставление может не работать.
- JAR локально НЕ собран и НЕ протестирован в игре; Java-код требует проверки в GitHub Actions.
